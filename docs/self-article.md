## 1. 記事作成における理論・品質基準（厳守ルール）

### A. 金融理論・クオンツ市場力学の厳密性
1. **概念の厳密化（出来高と平滑化の分離）：**
   - 単純移動平均やオシレーターなどを安易に「損益分岐点・平均取得単価」と混同しない。
   - 「出来高（Volume）を含まない価格トレンドの平滑化フィルター」「市場心理的な基準レート」として本質を解説する（VWAP等との違いを明確化）。
2. **市場構造と需給メカニズムの解像度（陰謀論の排除）：**
   - 「大口が個人をハメる」といった安直な物語化・擬人化を排す。
   - 「巨額注文をスリッページなく約定（Fill）させるための流動性プール（Liquidity Pool）の回収」という物理的な執行アルゴリズムとして解説する。
3. **機関投資家のリバランス・強制執行ロジック：**
   - 重要節目（200日線等）は単なるサポレジではなく、リスクパリティファンドや年金基金による「機械的なリスク資産削減（強制デレバレッジ）や売りヘッジ」のトリガーとして機能する物理現象を解説する。
4. **過剰最適化（カーブフィッティング）への警告：**
   - 特定のパラメータ自体に魔術的な優位性はなく、世界中の参加者が参照する「合意形成点（シェリングポイント）」であると明記。
   - バックテストの過剰最適化を警告し、周辺数値を用いた「感応度分析」の重要性を提示する。
5. **統計的トレードオフ（Type I / Type II エラー）：**
   - ダマシは「完全に防げるもの」ではなく、フィルター厳格化に伴う「偽陽性減少（Type I）」と「偽陰性増大・初動遅延（Type II）」のトレードオフであることを提示。
   - ダマシを「期待値設計における必要経費（フィルターコスト）」と定義する統計的思考を組み込む。
6. **時間軸サンプリングの限界とフラクタルの整合性：**
   - 時間軸固定サンプリングの限界（出来高集中期と閑散期の歪み）と適応型指標（KAMA等）に言及する。
   - 上位足の浅い押し目形成過程のノイズで下位足が刈られないよう、「投資ホライズン（期間）と許容ボラティリティ（ATR）の整合性」を明記する。

### B. 金融初学者への配慮と構成力
1. **直感的な導入:** 単語の成り立ち、計算期間がスライドするイメージ、突発ニュースと平滑化（ノイズ除去）の対比など、数式が苦手な読者でも視覚的に掴める図解・例えを冒頭に配置する。

## 2. UI / デザイン・技術実装仕様

1. **出力形式:** 
   - `<!DOCTYPE html>` や `<html>`、Markdownコードブロック（```html等）は含めず、`<div class="article-container ...">` から始まる**記事本文のみの単一HTMLコード**を出力。
2. **スタイリング:** 
   - `Tailwind CSS` を活用。ネイビー・スレート背景とゴールド/アンバーのアクセントによる高級金融メディアUI。
3. **数式表示（MathJax 3）：** 
   - インライン数式は `\( ... \)`、独立行数式は `$$ ... $$` を厳密に使用（生のTeXコード露出や文字化けを防止）。
4. **グラフィック・図解（必須）：**
   - `Chart.js` による動的比較グラフ、または `HTML5 Canvas`（レスポンシブ・交点計算・重なり防止バッジ付き）による波形・構造図を最低2箇所以上挿入。
5. **Wix iframe / スムーススクロール対応:**
   - 目次リンクは JavaScript で `scrollIntoView({ behavior: 'smooth' })` を実装し、iframe内でも確実に目的のセクションへジャンプ可能にする。
6. **テキスト処理:**
   - 生のMarkdown記法（`**...**` 等）を残さず、すべて `<strong class="...">...</strong>` 等の適切なHTMLタグへ変換。
7. **外部スクリプトの安全性:**
   - `polyfill.io` 等の不要・危険なスクリプトは一切読み込まない。
